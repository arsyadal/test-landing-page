# test-landing-page

> **AuraEdge Platform** — High-Performance Distributed Edge Compute & Stream Execution Landing Page.

Built with **React 19**, **Vite**, **TypeScript**, **Tailwind CSS v4**, and **Bun**.

Designed with **UI/UX Pro Max** design standards, tactile components inspired by **21st.dev**, and strictly verified against **Anti-Slop (R-01 to R-38)** principles.

---

## Features
- **Global PoP Edge Simulator**: Real-time interactive latency and route hop trace across 5 international edge regions with copyable cURL dispatch commands.
- **Interactive Stream Sandbox**: Live JSON payload transformer with instant byte compression calculation and DLP token redactor.
- **V8 Isolate Architecture Showcase**: Side-by-side technical benchmarks and 21st.dev-grade magnetic spotlight cards.
- **Dynamic Pricing Calculator**: Real-time volume and duration sliders calculating monthly cost estimates and legacy cloud savings.
- **Technical FAQ Accordion**: Keyboard-accessible (`Enter`/`Space`) responses to developer questions.
- **Developer Onboarding Form**: Full state machine (idle, loading, client validation error, and success state with confetti celebration).
- **Dual Theme Support**: Flawless Dark Mode and Light Mode with verified WCAG AA contrast.

## Getting Started

### Prerequisites
- [Bun](https://bun.sh/) (v1.2+) or Node.js (v20+)

### Installation
```bash
bun install
```

### Development Server
```bash
bun dev --port 5174
```
Open [http://localhost:5174](http://localhost:5174) in your browser.

### Production Build
```bash
bun run build
```
